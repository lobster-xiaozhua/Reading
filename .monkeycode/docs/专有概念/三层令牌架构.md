# 三层令牌架构

Atlas Design System 采用三层设计令牌架构，实现主题切换、暗黑模式和阅读主题的灵活控制。完整的设计系统组件库说明见 [模块/设计系统.md](../模块/设计系统.md)。

## 架构概览

```
L1 Primitive（原始值层）—— 不可变原子值
      ↓ 引用
L2 Semantic（语义层）—— 按用途命名，支持主题切换
      ↓ 引用
L3 Component（组件层）—— 各组件内部的 CSS 变量引用
```

## L1: Primitive（原始值）

文件: `packages/tokens/src/styles/primitive.css`

不可变的原子值，组件禁止直接引用。包括：

- **品牌色**: blue-1 ~ blue-10（10 级，主色 `#1890FF`）
- **强调色**: cobalt-1 ~ cobalt-10（10 级，主色 `#245BFF`）
- **暖橙营销色**: orange-1 ~ orange-5（5 级，用于 C 端 VIP 营销）
- **功能色**: success/green, warning/yellow, danger/red, info/cyan（各 5 级）
- **中性灰**: gray-1 ~ gray-14（14 级，从白到黑）
- **阅读主题色**: day/night/sepia/parchment 各 3 色
- **图表色**: chart-1 ~ chart-6

## L2: Semantic（语义层）

文件: `packages/tokens/src/styles/semantic.css`

按用途命名，引用 L1 变量。主题切换通过 `[data-theme]` 属性改变 L2 指向：

- **文本色**: `--color-text-primary`、`--color-text-secondary`、`--color-text-tertiary`、`--color-text-disabled`、`--color-text-inverse`
- **背景色**: `--color-bg-page`、`--color-bg-elevated`、`--color-bg-component`、`--color-bg-hover`、`--color-bg-active`
- **边框色**: `--color-border-default`、`--color-border-hover`、`--color-border-active`
- **品牌色**: `--color-brand`、`--color-brand-hover`、`--color-brand-active`
- **反馈色**: `--color-success`、`--color-warning`、`--color-danger`、`--color-info`
- **字体**: `--font-sans`、`--font-serif`、`--font-mono`、`--font-size-*`、`--font-weight-*`
- **间距**: `--space-1` ~ `--space-13`（4px 基准）
- **圆角**: `--radius-none` ~ `--radius-full`（8 档）
- **阴影**: `--shadow-1` ~ `--shadow-5`（5 级）
- **动效**: `--dur-100` ~ `--dur-500`（5 档），`--ease-*`（4 种缓动）
- **z-index**: `--z-base` ~ `--z-max`（6 级）
- **图标尺寸**: `--icon-size-xs` ~ `--icon-size-2xl`（详见 [图标库](../模块/图标库.md)）

### 暗黑模式

```css
[data-theme='dark'] {
  --color-text-primary: var(--gray-1);
  --color-bg-page: var(--gray-13);
  /* 暗色模式下 L2 指向深色背景的 L1 值 */
}
```

## L3: Component（组件层）

各组件 CSS 文件引用 `var(--color-*)` 语义变量，不直接引用 L1 原始值。

```css
.novel-btn--primary {
  background-color: var(--color-brand);
  color: var(--color-text-inverse);
}
```

## 主题系统

### UI 主题

- `light` / `dark` / `system`（跟随系统）
- 通过 `[data-theme]` 属性实现
- 持久化到 localStorage
- B 端暗黑模式集成见 [模块/前端B端管理后台.md](../模块/前端B端管理后台.md)

### 阅读主题

- `day` / `night` / `sepia` / `parchment`
- 通过 `[data-reader-theme]` 属性实现
- 独立于 UI 主题，互不干扰

### React Provider

```tsx
import { ThemeProvider, useTheme, useReaderTheme } from '@novel/tokens/react';

function App() {
  return (
    <ThemeProvider>
      <YourApp />
    </ThemeProvider>
  );
}

function YourComponent() {
  const { theme, setTheme, readerTheme, setReaderTheme } = useTheme();
  const { readerTheme } = useReaderTheme();
}
```

## 无障碍

- 高对比度模式: `prefers-contrast: more` 媒体查询
- 减弱动效: `prefers-reduced-motion: reduce` 媒体查询
- WCAG 2.2 AA 对比度合规（提供对比度合规表）

## Tailwind 集成

所有语义 CSS 变量映射为 Tailwind 工具类：

```css
text-primary        → color: var(--color-text-primary)
bg-page             → background-color: var(--color-bg-page)
border-default      → border-color: var(--color-border-default)
shadow-1            → box-shadow: var(--shadow-1)
font-serif          → font-family: var(--font-serif)
```

## JS/TS 导出

```ts
import { tokens } from '@novel/tokens';

tokens.color.brand;             // '#1890FF'
tokens.color.bgPage;            // '#FFFFFF'
tokens.font.fontSize.xl;        // '1.25rem'
tokens.space[4];                // '16px'
```
