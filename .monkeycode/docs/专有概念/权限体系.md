# 权限体系

B 端管理后台采用四层权限体系，从菜单级到数据级逐层细化权限控制。鉴权流程见 [双Token鉴权](./双Token鉴权.md)，B 端前端实现见 [模块/前端B端管理后台.md](../模块/前端B端管理后台.md)。

## 四层架构

```
┌─────────────────────────────────────────────────────┐
│  L1 菜单级权限                                       │
│  侧边栏菜单根据角色权限动态渲染                        │
├─────────────────────────────────────────────────────┤
│  L2 页面级权限                                       │
│  RequirePermission 路由守卫，无权限显示 403           │
├─────────────────────────────────────────────────────┤
│  L3 操作级权限                                       │
│  Authorized 组件控制按钮/操作可见性                    │
├─────────────────────────────────────────────────────┤
│  L4 数据级权限                                       │
│  请求头 X-Data-Scope 透传，后端严格校验                │
└─────────────────────────────────────────────────────┘
```

## 权限点

共 20 项权限点，按模块分组：

### 作品管理

| 权限标识 | 说明 |
|----------|------|
| `novel.list` | 查看作品列表 |
| `novel.create` | 创建作品 |
| `novel.edit` | 编辑作品 |
| `novel.delete` | 删除作品 |
| `novel.shelve` | 上架/下架作品 |

### 章节管理

| 权限标识 | 说明 |
|----------|------|
| `chapter.list` | 查看章节列表 |
| `chapter.create` | 创建章节 |
| `chapter.edit` | 编辑章节 |
| `chapter.delete` | 删除章节 |

### 审核管理

| 权限标识 | 说明 |
|----------|------|
| `audit.list` | 查看审核队列 |
| `audit.approve` | 审核通过 |

### 作者管理

| 权限标识 | 说明 |
|----------|------|
| `author.list` | 查看作者列表 |

### 稿费管理

| 权限标识 | 说明 |
|----------|------|
| `royalty.list` | 查看稿费明细 |

### 用户管理

| 权限标识 | 说明 |
|----------|------|
| `user.list` | 查看用户列表 |

### 系统管理

| 权限标识 | 说明 |
|----------|------|
| `permission.assign` | 分配角色权限 |
| `system.config` | 管理系统配置 |

## 角色定义

5 个内置角色，权限不可修改：

| 角色 | 标识 | 说明 |
|------|------|------|
| 超级管理员 | `super-admin` | 所有权限，包括系统配置和权限分配 |
| 内容管理员 | `content-admin` | 作品、章节、审核、作者管理 |
| 运营管理员 | `operation-admin` | 作品、章节、用户管理 |
| 财务管理员 | `finance-admin` | 稿费管理 |
| 审核员 | `auditor` | 审核队列、审核操作 |

### 角色权限映射

```python
BUILTIN_ROLE_PERMISSIONS = {
    "super-admin": ALL_PERMISSIONS,
    "content-admin": [
        "novel.list", "novel.create", "novel.edit", "novel.shelve",
        "chapter.list", "chapter.create", "chapter.edit", "chapter.delete",
        "audit.list", "audit.approve", "audit.reject",
        "author.list", "author.edit",
    ],
    "operation-admin": [
        "novel.list", "novel.create", "novel.edit", "novel.shelve",
        "chapter.list", "chapter.create", "chapter.edit", "chapter.delete",
        "user.list", "user.edit",
    ],
    "finance-admin": [
        "royalty.list", "royalty.export",
    ],
    "auditor": [
        "audit.list", "audit.approve", "audit.reject",
    ],
}
```

## 前端实现

### 菜单级权限（SiderMenu）

```typescript
// 菜单配置包含 permissions 字段
const menuConfig = [
  {
    key: '/novel',
    label: '作品管理',
    permissions: ['novel.list'],
  },
  {
    key: '/audit',
    label: '内容审核',
    permissions: ['audit.list'],
  },
];
```

### 页面级权限（RequirePermission）

```tsx
<Route
  path="/permission"
  element={
    <RequirePermission permissions={['permission.assign']}>
      <PermissionPage />
    </RequirePermission>
  }
/>
```

### 操作级权限（Authorized）

```tsx
<Authorized permissions={['novel.create']}>
  <Button type="primary">新建作品</Button>
</Authorized>
```

### 数据级权限（data-scope）

```typescript
// 请求头透传
const headers = buildDataScopeHeaders(currentAdmin);
// { 'X-Data-Scope': 'self' | 'dept' | 'all' }
```

## 权限分配界面

`PermissionPage` 提供可视化的角色权限管理：

- 左侧：角色列表（显示角色名、用户数、是否内置）
- 右侧：权限树（按模块分组展示权限点）
- 超级管理员权限为只读（内置角色不可修改）
- 支持编辑角色名称和描述
