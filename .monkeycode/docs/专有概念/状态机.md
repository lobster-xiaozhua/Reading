# 状态机

作品、章节、稿费的状态流转通过 `StateMachine` 基类统一管理，确保状态转换的合法性和可追溯性。作品运营端完整流程见 [作品状态流转](./作品状态流转.md)。

## 实现

文件: `backend/app/utils/state_machine.py`

### 基类 `StateMachine`

```python
class StateMachine(ABC):
    states: list[str]         # 合法状态列表
    transitions: dict[str, list[str]]  # 状态转换图

    def can_transition(self, current: str, target: str) -> bool
    def transition(self, current: str, target: str) -> str
    def next_states(self, current: str) -> list[str]
```

## 作品状态机

`NovelStateMachine` — 管理作品完整生命周期。

### 状态

| 状态 | 说明 |
|------|------|
| `draft` | 草稿（初始状态） |
| `pending` | 待审核（提交审核后） |
| `published` | 已发布（审核通过后上架） |
| `offline` | 已下架 |

### 状态转换图

```
draft ────提交审核────→ pending ────审核通过+上架────→ published
  ↑                                                     │
  │                                                     │
  └─────────────────────重新上架─────────────────────────┘
                                                        │
                                                    下架操作
                                                        │
                                                        ↓
                                                     offline
                                                        │
                                                    重新上架
                                                        │
                                                        ↓
                                                   published
```

### 合法转换

| 当前状态 | 可转换到 |
|----------|----------|
| `draft` | `pending` |
| `pending` | `published`（审核通过） |
| `published` | `offline`（下架） |
| `offline` | `published`（重新上架） |

## 章节状态机

`ChapterStateMachine` — 与作品状态机类似，增加独立的状态流转。

### 状态

| 状态 | 说明 |
|------|------|
| `draft` | 草稿 |
| `pending` | 待审核 |
| `published` | 已发布 |
| `offline` | 已下架 |

### 转换

```
draft → pending → published → offline → published
```

## 稿费状态机

`RoyaltyStateMachine` — 管理稿费结算状态。

### 状态

| 状态 | 说明 |
|------|------|
| `pending` | 待结算 |
| `settled` | 已结算 |
| `withdrawn` | 已提现 |

### 转换

```
pending → settled → withdrawn
```

## 使用方式

```python
from app.utils.state_machine import NovelStateMachine

# 检查是否可以转换
if NovelStateMachine.can_transition(current="draft", target="pending"):
    novel.status = "pending"

# 获取允许的下一个状态
next_states = NovelStateMachine.next_states(current="published")
# ['offline']
```
