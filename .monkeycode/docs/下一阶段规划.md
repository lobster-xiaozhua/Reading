## 依赖关系图

```
S1 ── S2 ── S3 ── S4
                │
                └── S5（可并行，建议收尾阶段执行）
```

- **S1 是 S2 的前置**：Storybook 初始化后才能做组件级 i18n 验证
- **S2 是 S3 的前置**：新功能开发应直接使用 i18n 而非中文
- **S3 与 S4 可并行**：B 端功能完善与 C 端 H5 开发互不依赖
- **S5 建议收尾阶段**：性能/无障碍/测试是上线前的最后关卡
