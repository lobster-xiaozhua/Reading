# Atlas Design System · 设计语言重塑方案 V2.0

> 覆盖范围：C 端品牌视觉、B 端数据可视化、设计系统底层重构、微交互与动效体系
> 基于现有 `@novel/tokens` V1.0 三层令牌架构，做增量式增强而非推倒重来。

---

## 一、品牌定位与设计原则

### 品牌关键词

**沉浸 · 温度 · 精炼 · 可信赖**

- **沉浸**：阅读器是核心战场，所有 UI 向内容让路，用微动效和氛围光提升沉浸感
- **温度**：暖色调辅助色（橙/金/玫瑰色）拉近读者距离，避免纯工具感
- **精炼**：信息密度克制，留白充足，每个像素有目的
- **可信赖**：B 端数据呈现清晰、稳定、可预测，操作反馈即时

### 设计原则

1. **内容优先**：阅读体验高于一切装饰，UI 不抢内容风头
2. **渐进式揭露**：不一次性展示所有信息，引导用户自然发现
3. **一致 > 完美**：全站统一间距/圆角/动效曲线，比局部最优更重要
4. **可访问性内置**：对比度 4.5:1、焦点可见、触屏友好是默认要求，不是加分项

现有品牌色仅有一组蓝。新增"品牌红"和"品牌金"语义用途，避免页面中直接引用 `--color-rose` / `var(--orange-3)` 等原始令牌：

## 三、C 端品牌视觉重塑

### 3.1 发现页重构方案

**现有问题**：
- 卡片布局平坦，缺少层次感
- 编辑精选区使用 CSS 类名覆盖，无统一 `BookCard` 变体
- 分类入口使用旋转色阵列，视觉随机感强
- 排行榜 tab 样式朴素，Top3 奖牌色未在排行榜中展示

**改造方案**：

#### 3.1.1 Banner 区：增加氛围光渐变

```css

  border-radius: var(--radius-xl);
  overflow: hidden;
  background: var(--gradient-brand-subtle);

.discover-page__banner::after {
  content: '';
  position: absolute;
  inset: 0;
  background: linear-gradient(90deg, 
    rgba(0,0,0,0.4) 0%, 
    transparent 30%, 
    transparent 70%, 
    rgba(0,0,0,0.4) 100%

  pointer-events: none;
}
```

#### 3.1.2 编辑精选：卡片升级

```tsx

  book={toBook(b)}
  variant="featured"   // 新增
```

## 五、微交互与动效体系

### 5.1 页面级过渡

利用 React Router 的 `useNavigation` 或自定义 `AnimatedOutlet`，在路由切换时执行页面过渡。C 端使用 `slideIn` 方向性动画，B 端使用 `fadeIn` 快速切换。

```tsx
// AnimatedOutlet.tsx — 用于 B 端内容区
export function AnimatedOutlet({ children }: { children: ReactNode }) {
  const location = useLocation();
  return (
    <div key={location.pathname} className="page-fade-in">
      {children}
    </div>
  );
}
```

```css
.page-fade-in {
  animation: pageFadeIn 200ms var(--ease-standard) both;
}

@keyframes pageFadeIn {
  from {
    opacity: 0;
    transform: translateY(8px);
  }
  to {
    opacity: 1;
    transform: translateY(0);
  }
}
```

### 5.2 列表入场动画

C 端发现页的分类、排行榜、热门推荐等列表项，使用 `stagger` 交错入场：

```tsx
// stagger 动画 hook
function useStaggerEnter(index: number, baseDelay = 50) {
  const delay = index * baseDelay;
  return {
    animation: `staggerEnter 300ms var(--ease-decelerate) both`,
    animationDelay: `${delay}ms`,
  };
}
```

```css
@keyframes staggerEnter {
  from {
    opacity: 0;
    transform: translateY(12px);
  }
  to {
    opacity: 1;
    transform: translateY(0);
  }
}
```

## 九、回归风险与保障

| 风险 | 缓解措施 |
|------|---------|
| 令牌层改动影响 C+B 两端 | 只新增令牌不删改，保证 V1.0 兼容性 |
| 动效引入 CLS | 所有动效使用 `transform/opacity`，不碰 `width/height/top/left` |
| 触屏 hover 粘滞 | 所有悬浮效果加 `@media (hover: hover)` 包裹 |
| 减弱动效偏好 | 全局 `prefers-reduced-motion: reduce` 覆盖所有动效持续时间 |
| 暗色模式对比度 | 在所有新增色上验证 WCAG 4.5:1 |
