# 监控巡检

## 概述

基于 Playwright 的智能巡检系统，覆盖后端健康检查、API 接口、前端页面渲染和业务链路。API 接口列表见 [INTERFACES.md](../INTERFACES.md)。

- 框架: Playwright 1.62
- 测试位置: `monitoring/checks/`
- 配置文件: `monitoring/playwright.config.ts`
- 检查总数: 41 项

## 配置

```typescript
// playwright.config.ts 核心配置
{
  timeout: 30000,        // 每个测试超时 30s
  retries: 1,            // 失败重试 1 次
  workers: 1,            // 单 worker 顺序执行
  reporter: ['list', ['json', { outputFile: 'results.json' }]],
  // 6 个 Playwright 项目
  projects: ['backend', 'api-b-end', 'api-c-end', 'pages-b-end', 'pages-c-end', 'business-flow'],
}
```

## 运行方式

```bash
# 全量 41 项检查
pnpm run monitor

# 分类运行
pnpm run monitor:health    # 仅健康检查
pnpm run monitor:api       # 仅 API 接口巡检
pnpm run monitor:page      # 仅前端页面渲染巡检
pnpm run monitor:flow      # 仅业务链路巡检

# 手动运行（带参数）
bash monitoring/run.sh --only health
bash monitoring/run.sh --report json
```

## 运行脚本

`monitoring/run.sh` 在启动测试前自动检查：

- 后端服务（端口 8000）是否存活
- B 端管理后台（端口 5174）是否存活
- C 端 Web（端口 5173）是否存活
- 输出报告到 `monitoring/reports/` 目录
