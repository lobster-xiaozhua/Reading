# 设计系统

## 概述

Atlas Design System 是小说阅读平台的设计系统，提供从设计令牌到组件的完整设计工程化方案。

- 包名: `@novel/tokens`（设计令牌）、`@novel/components`（C 端组件）、`@novel/b-end`（B 端组件）
- 版本: 1.0.0（tokens/components）、0.1.0（b-end）

## 包结构

```
packages/
├── tokens/         # 设计令牌（L1 Primitive + L2 Semantic + 主题系统）
├── components/     # C 端通用组件（17 个通用 + 阅读器 + 扩展组件）
└── b-end/          # B 端专用组件（22 个 Ant Design 封装组件 + 图表 + 工具）
```

## 组件体系

### C 端组件 (`@novel/components`)

17 个通用组件，按功能分层：

| 分层 | 组件 | 说明 |
|------|------|------|
| P2.1 原子层 | Button, Input, Tag, Badge, Avatar, Switch, Checkbox, Radio | 基础交互元素 |
| P2.2 反馈层 | Tooltip, Popover, Dropdown, Alert, EmptyState, Skeleton | 用户反馈与状态 |
| P2.3 容器层 | Modal, Drawer, Tabs, Pagination, Select | 布局与容器 |
| P2.4 业务原子 | BookMeta, ContentStatus | 小说业务原子 |
| P3 C 端基础 | RatingStars, BookCard, NotificationBadge, ChapterList, Bookshelf | 读者端核心 |
| P4 阅读器 | Reader, ReaderSettings, ReadingProgress | 阅读器全套 |
| P6 C 端扩展 | RankingBoard, TagCloud, Comment, RewardButton, BookRecommend | 社区互动 |

### B 端组件 (`@novel/b-end`)

22 个 Ant Design 封装组件，按功能分组（B 端页面使用方式见 [模块/前端B端管理后台.md](./前端B端管理后台.md)）：

| 分组 | 组件 |
|------|------|
| 展示与导航 | BPageHeader, BFilterBar, BStatisticCard, BBatchActionBar, BBreadcrumb, BResult |
| 表单与数据 | BTable, BForm, BFormItem, BUpload, BDatePicker, BSteps, BCascader, BTree, BTreeSelect, BTransfer, BRate, BProgress, BDescriptions, BTimeline |
| 专项 | ChapterEditor（TipTap 富文本）, BContentReview, BAuthorManager |
| 稿费 | BRoyaltyDetail, SettlementFlow |
| 图表 | BLineChart, BColumnChart, BPieChart, BAreaChart, BHeatmap, BGauge + 5 个业务图表 |

### 封装模式

B 端组件采用 Ant Design 封装模式：

```tsx
// 在 Ant Design 组件上设置业务默认值并透传其余 props
export function BTable<T>(props: TableProps<T>) {
  return (
    <Table
      size="middle"
      pagination={{ defaultPageSize: 20, showSizeChanger: true, ...props.pagination }}
      {...props}
    />
  );
}
```

C 端 Hooks 在 [模块/前端C端.md](./前端C端.md) 的阅读器章节有详细使用示例。

## 钩子（Hooks）

### 通用异步状态

```tsx
import { useAsyncState } from '@novel/components';

const { data, loading, error, execute } = useAsyncState(
  async () => await fetcher.getBook(bookId),
  {
    immediate: true,
    loadingDelay: 1000,  // 1 秒内完成不显示加载态
    deps: [bookId],
  }
);
```

### 阅读器设置

```tsx
import { useReaderSettings } from '@novel/components';

const { settings, updateSetting } = useReaderSettings();
// settings.fontSize = 18 (14-24, 6 档)
// settings.lineHeight = 'standard' (compact/standard/loose)
// settings.fontFamily = 'serif' (serif/song/hei/kai)
// settings.theme = 'day' (day/night/eye/parchment)
// settings.pageMode = 'slide' (slide/scroll/click)
```

## 图表系统

B 端图表基于 `@ant-design/charts`，共享配置：

- 默认高度 320px
- 6 色色板取自 `--color-chart-1~6` CSS 变量
- 暗黑模式自动切换色板
- 空数据占位处理
- 5 个小说专用业务图表：字数增长趋势、阅读热力图、阅读转化漏斗、排行趋势、分类分布

## 构建方式

### tokens 构建

```bash
pnpm --filter @novel/tokens build
# 输出: dist/styles/*.css, dist/index.js, dist/dtcg.json
```

### components 构建

```bash
pnpm --filter @novel/components build
# 输出: dist/index.js, dist/styles.css
```

### b-end 构建

```bash
pnpm --filter @novel/b-end build
# 输出: dist/index.js
```
