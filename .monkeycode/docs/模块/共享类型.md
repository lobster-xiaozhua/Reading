# 共享类型

## 概述

跨 C/B 端共享的 TypeScript 类型定义，零运行时依赖。后端 API 响应使用 `CamelModel` 自动对齐命名，接口列表见 [INTERFACES.md](../INTERFACES.md)。

- 包名: `@novel/types`
- 版本: 0.1.0
- 纯类型包（编译后仅生成 `.d.ts` 声明文件）

## 类型分类

### 枚举与类型别名 (`enums.ts`)

```typescript
// 书籍标识
type BookFlag = 'vip' | 'free-limited' | 'editor-pick' | 'hot';

// 书籍分类
type BookCategory = 'xuanhuan' | 'xianxia' | 'urban' | 'history'
  | 'scifi' | 'wuxia' | 'game' | 'suspense' | 'romance' | 'other';

// 合同类型
type ContractType = 'buyout' | 'share' | 'guarantee-share';

// 结算状态
type SettlementStatus = 'pending' | 'settled' | 'withdrawn';

// 审核相关
type AuditLevel = 1 | 2 | 3;
type AuditResult = 'approved' | 'rejected';
type RejectReason = 'content-quality' | 'sensitive-words' | 'format-issue' | 'other';
type OfflineReason = 'violation' | 'author-request' | 'contract-expired' | 'other';
```

### 书籍类型 (`novel.ts`)

```typescript
// 基础字段
interface NovelBase {
  id: string;
  title: string;
  author: string;
  cover: string;
  category: BookCategory;
  tags: string[];
  wordCount: number;
  intro: string;
  lastUpdated: string;
}

// C 端书籍摘要
interface CNovelSummary extends NovelBase {
  status: CNovelStatus;
  rating: number;
  ratingCount: number;
  followCount: number;
  clickCount: number;
}

// B 端书籍详情
interface BNovelDetail extends NovelBase {
  authorId: number;
  status: BNovelStatus;
  publishedAt?: string;
  shelvedAt?: string;
  reason?: string;
  createdAt: string;
}

// 章节基础
interface ChapterBase {
  id: string;
  novelId: string;
  index: number;
  title: string;
  wordCount: number;
  isVip: boolean;
}
```

### 用户类型 (`user.ts`)

```typescript
// 基础用户
interface UserBase {
  id: number;
  username: string;
  nickname: string;
  avatar: string;
}

// B 端管理员
interface AdminUser extends UserBase {
  roles: string[];
  permissions: string[];
  email: string;
  status: 'active' | 'disabled';
}

// C 端读者
interface ReaderUser extends UserBase {
  level: number;
  isVip: boolean;
  vipExpireAt?: string;
}
```

### 权限点（详见 [权限体系](../专有概念/权限体系.md)）

## 使用方式

```typescript
import type { CNovelSummary, BNovelDetail, BookCategory } from '@novel/types';
import type { AdminUser, Permission } from '@novel/types';
import type { NovelBase, ChapterBase } from '@novel/types';
import type { BookFlag, AuditLevel, SettlementStatus } from '@novel/types';
```

## 设计原则

- 只包含 C/B 两端共享的类型
- 端特有的类型分别定义在各自项目的 `src/api/types.ts` 中
- 纯类型导出，不包含运行时逻辑
- 与后端 Pydantic Schema 的 `CamelModel` 命名对齐（camelCase）
