# 图标库

## 概述

内置 85 个 SVG 图标，60 个通用图标 + 25 个小说专用图标。图标尺寸映射到 [三层令牌架构](../专有概念/三层令牌架构.md) 的 `--icon-size-*` 语义变量。

- 包名: `@novel/icons`
- 版本: 1.0.0
- 渲染规范: 24x24 viewbox, 1.8px 描边, `currentColor` 着色, `round` linecap/linejoin, `memo` 包裹

## 使用方式

### 基础用法

```tsx
import { Icon } from '@novel/icons';
import { ActionAdd, NovelHeart, NavigationBack } from '@novel/icons';

// 使用 Icon 基础组件
<Icon icon="action-add" size="md" aria-label="添加" />

// 直接使用具名导出
<ActionAdd size="lg" />
<NovelHeart size="xl" />
```

### API

```tsx
interface IconProps extends Omit<SVGProps<SVGSVGElement>, 'width' | 'height'> {
  size?: 'xs' | 'sm' | 'md' | 'lg' | 'xl' | '2xl';
  // 映射到 --icon-size-* 令牌
  'aria-label'?: string;
}
```

### 聚合导出

```tsx
import { allIcons, iconsByKebab } from '@novel/icons';

// allIcons: 按分类分组的图标组件
// iconsByKebab: kebab-case 名称到组件的映射
const IconComponent = iconsByKebab['action-add'];
```

## 图标规范

| 规范 | 值 |
|------|-----|
| Viewbox | 24x24 |
| 描边宽度 | 1.8px |
| 着色 | `currentColor` |
| Linecap | `round` |
| Linejoin | `round` |
| 性能优化 | `React.memo` 包裹 |
| 尺寸 | 6 档（`--icon-size-*` 令牌） |

## 构建方式

图标基于元数据文件自动生成：

```
icons-meta.mjs (元数据定义) → scripts/build.mjs → icons.tsx (自动生成)
```

每个图标生成一个独立的 memo 组件，同时生成分类分组、聚合导出和 kebab-case 查找表。
