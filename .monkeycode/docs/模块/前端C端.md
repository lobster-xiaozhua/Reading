# C 端读者 Web 站

## 概述

面向读者的小说阅读平台前端，提供发现、阅读、社区互动、个人中心等完整功能。设计系统基于 [设计系统](./设计系统.md) 和 [三层令牌架构](../专有概念/三层令牌架构.md)。

- 技术栈: React 19 + Vite 5 + TypeScript + Tailwind CSS + Zustand
- 构建工具: Vite 5
- 开发端口: 5173
- 包名: `@novel/web`

## 页面功能

### 发现页 (`/`)

内容聚合首页，从上到下依次为：

- Banner 轮播（自动播放，左右箭头切换）
- 本周热门（横向滚动卡片列表）
- 限时免费（倒计时 + 网格卡片）
- 分类导航（图标网格，点击跳转分类页）
- 左侧编辑推荐 + 右侧排行榜（4 个 Tab: 人气/收藏/月票/新书）

### 书籍详情 (`/book/:bookId`)

- 封面 + 元信息 + 统计（评分/追读/点击）
- 操作按钮（开始阅读/加入书架/打赏）
- 评分分布（5 星柱状图）
- 3 个 Tab：目录/评论/打赏
- 相关推荐

### 阅读器 (`/read/:bookId/:chapterId?`)

全屏沉浸式阅读体验：

- 6 档字号（14-24px）、3 档行距、4 种字体、4 套阅读主题
- 3 种翻页模式（滑动/滚动/点击）
- 目录抽屉（右侧滑出）
- 文本选择弹出（笔记/高亮）
- 阅读进度自动存储
- 离线缓存（IndexedDB，50MB LRU）

### 分类页 (`/category`)

- 左侧分类树，右侧书籍网格
- 排序: 人气/收藏/最新/完结
- 状态筛选: 全部/连载/完结
- 标签筛选按钮
- 分页导航
- 筛选状态同步 URL 参数

### 搜索页 (`/search`)

- 搜索输入（300ms 防抖）
- 自动补全建议（按类型分组: 书籍/作者/标签）
- 搜索历史（最近 10 条，localStorage 持久化）
- 热搜词
- 搜索结果分页加载

### 个人中心 (`/profile`)

- 用户卡片（头像、昵称、等级、VIP 标识、阅读统计）
- 5 个 Tab：书架/阅读历史/书单/打赏记录/设置

### 阅读统计 (`/stats`)

- 统计概览（3 个计数卡片，数字动画）
- 53 周阅读热力图
- 阅读偏好分布（环形图）
- 成就徽章网格

### 其他页面

- **VIP 订阅** (`/vip`): 套餐选择（月卡/季卡/年卡）、支付方式、橙色主题
- **追更** (`/follow`): 4 个 Tab、左滑取消关注、标记全部已读
- **登录** (`/login`): 登录/注册切换

## 状态管理

使用 Zustand + persist 中间件，4 个 Store：

| Store | 持久化 Key | 主要数据 |
|-------|-----------|----------|
| `authStore` | `atlas-reader-auth` | Token、用户信息 |
| `historyStore` | `atlas-history-store` | 阅读进度（按书 ID 索引） |
| `searchStore` | `atlas-search-store` | 搜索历史 |
| `userStore` | `atlas-user-store` | 用户资料、书架 ID 列表 |

## 离线与网络自适应

- **离线缓存**: IndexedDB 存储章节内容，50MB LRU 淘汰策略
- **网络降级**: 检测 2g/3g/4g/saveData，弱网时缩小预加载范围
- **Service Worker**: 生产环境注册，支持离线阅读

## 性能监控

启动时自动注册性能观察器：

- LCP（最大内容绘制）
- INP（交互到下一次绘制）
- CLS（累计布局偏移）
- TTI（可交互时间）
- 章节切换耗时（自定义 metric）

## 样式方案

- Tailwind CSS 3 + 设计令牌 CSS 变量
- 组件级 CSS 文件（BEM 命名，`novel-*` 前缀）
- 图标使用 [图标库](./图标库.md) 的 85 个 SVG 图标
- 响应式断点: 5 个断点（移动端优先）
- 触控: 移动端 `min-height: 44px`、`min-width: 44px`
- 安全区域: `env(safe-area-inset-bottom)` 适配
