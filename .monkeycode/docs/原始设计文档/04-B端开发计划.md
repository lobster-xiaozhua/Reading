### 0.2 B 端关键约束

- **令牌铁律**：严格遵循三层 Token 架构（L1 Primitive → L2 Semantic → L3 Component），组件代码禁止裸色值，CI 拦截违规实现（与 C 端一致，01 §4.5、02 §0）。
- **Ant Design 基座**：B 端基于 Ant Design 5.x，通过 `ConfigProvider` + CSS Variables 模式消费语义令牌，**不发明与 AntD 冲突的交互模式**（04 §2.3）。所有 AntD 默认行为（表格排序/分页/筛选、表单校验、弹窗层级）保持不变。
- **PC 优先**：设计基准 1440×900，开发基准 1440px 宽度，最小支持宽度 1280px，低于此触发横向滚动，**不适配移动端**（04 §1.3）。
- **色彩策略**：B 端使用通用语义令牌，**不使用 C 端暖橙/玫红等情感色**（04 §3.1）。品牌色锁定 `--color-brand`（#1890FF = brand-7），B 端不调整品牌色色值。
- **效率优先**：高频操作路径最短化（核心操作 ≤ 3 次点击）、批量操作全程支持、键盘友好（Ctrl+S / Ctrl+Enter / Esc / `/`）、筛选状态持久化到 URL（04 §2.1）。
- **容错性**：破坏性操作二次确认 + 可撤销；高危操作（永久删除作品）需输入名称匹配（04 §2.4、§9.5）。

### 0.3 B 端复用边界铁律（V1.1 新增，审查 #1）

**B 端组件基座统一为 Ant Design 5.x**，禁止混用 C 端 Atlas 自研组件库（`@novel/components`）的**基础组件**，否则将导致：两套 Button/Modal/Tabs 视觉与交互不一致、主题切换走两条路径（CSS Variables vs ConfigProvider JS token）、无障碍焦点态两套实现。

| 类别 | 包内符号 | B 端是否可用 | 替代方案 |
| --- | --- | --- | --- |
| **基础组件**（Button/Input/Select/Modal/Drawer/Tabs/Tag/Badge/Tooltip/Popover/Dropdown/Avatar/Switch/Checkbox/Radio/Alert/Message/Notification/EmptyState/Skeleton/Pagination） | `@novel/components` | ❌ **禁用** | 一律从 `antd` 导入 |
| **状态 Hook** | `@novel/components/useAsyncState` | ✅ 可用 | 纯逻辑 Hook，无 UI 依赖 |
| **C 端业务组件**（BookCard/Bookshelf/ChapterList/Reader/ReaderSettings/RankingBoard/TagCloud/Comment/RewardButton/BookRecommend/ReadingProgress/BookMeta/ContentStatus/RatingStars/NotificationBadge） | `@novel/components` | ⚠️ 评估后用 | 仅当 AntD 无对应能力且组件无 C 端视觉绑定 |
| 令牌 | `@novel/tokens` | ✅ 复用 + 扩展 | 包括 chart-* |
| 图标 | `@novel/icons` | ✅ 复用 | B 端仅使用通用图标 |

**强制措施**：
1. `apps/admin/tsconfig.json` 增加 `paths` 黑名单，禁止 `import { Button, Input, Modal, ... } from '@novel/components'`。
2. `apps/admin/eslint.config.js` 增加 `no-restricted-imports` 规则，对禁用符号报错。
3. CI token-scan 阶段追加导入审计脚本，发现违规立即阻断。

- P6 与 P4 并行：权限组件 `<Authorized>` 与菜单级/操作级粒度控制需在 P4 落地时同步接入（会话/路由守卫已由 P0 提供）。

## 4. 关键技术决策清单

需在 P0 ~ P1 阶段拍板，避免后期返工：

| 决策项 | 候选 | 倾向 | 理由 |
| --- | --- | --- | --- |
| 组件基座 | Ant Design 5.x / 自研 / Arco Design | Ant Design 5.x | 04 §1.4 明确指定，生态成熟 |
| AntD 主题桥接 | less 变量 / ConfigProvider token / CSS Variables | ConfigProvider + CSS Variables | 04 §11.6 推荐，性能优避免全树重渲染 |
